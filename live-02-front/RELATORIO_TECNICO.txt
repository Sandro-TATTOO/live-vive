# RELATÓRIO TÉCNICO - APP LIVE STREAMING FLUTTER
## Live 02 Front - Estrutura completa + dependências (Abril 2024)

## 🏗️ ARQUITETURA GERAL
```
FLUTTER WEB (Chrome) 
├── STATE: Provider 6.1.2
├── REALTIME: Supabase 2.6.1 (auth + postgres_changes)
├── VIDEO: LiveKit 2.7.0 (viewer/publisher)
├── HTTP: Backend FastAPI :8000
├── SUPABASE: DB messages + auth anon
└── MODEL-VIEW-SERVICE clean arch
```

**FLUXO**:
```
1. HomeScreen (Grid LiveCards)
2. Tap → LiveRoomScreen(streamId)
3. joinLive() → LiveKit.connect() + ChatOverlay
4. leaveLive() + dispose()
```

## 🛠️ SERVIÇOS EXTERNOS
```
BACKEND FASTAPI (:8000):
├── GET /streams/live          → List<StreamModel>
├── GET /streams/{id}/viewer-token → LiveKit token
├── POST /streams/{id}/join    → Presence (user_id)
├── POST /streams/{id}/leave   → Presence
└── GET /streams/{id}          → {viewer_count}

SUPABASE:
├── postgres_changes('messages')
├── auth anon (currentUser.id)
└── stream_id filter

LIVEKIT CLOUD:
└── wss://livestreamapp-ghcjo92o.livekit.cloud
```
