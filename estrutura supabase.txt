     IA SUPABASE

Você é um arquiteto de banco de dados especialista em Supabase e PostgreSQL.

Crie o esquema completo para uma plataforma de live streaming com economia virtual, presentes, recompensas e sistema VIP.

A plataforma utiliza LiveKit para streaming em tempo real e Supabase para backend.

Requisitos principais da aplicação:

1. SISTEMA DE USUÁRIOS

Usuários são autenticados via Supabase Auth.

Crie uma tabela chamada profiles com os campos:

* id (uuid, referência para auth.users)
* username (text)
* avatar_url (text)
* created_at (timestamptz default now())

Cada usuário deve ter apenas um profile.

---

2. SISTEMA DE STREAMING

Crie uma tabela streams com:

* id (uuid primary key)
* creator_id (uuid referência profiles.id)
* title (text)
* started_at (timestamptz)
* ended_at (timestamptz)

Uma live é considerada ativa quando ended_at é NULL.

---

3. CHAT DA LIVE

Crie tabela messages:

* id uuid primary key
* stream_id uuid referência streams.id
* user_id uuid referência profiles.id
* content text
* created_at timestamptz default now()

Regras:

* mensagens só podem ser enviadas quando a live estiver ativa
* usar Row Level Security

Criar policy para INSERT verificando:

streams.ended_at IS NULL

---

4. SISTEMA DE CARTEIRA

Crie tabela wallets:

* id uuid primary key
* user_id uuid referência profiles.id
* balance integer default 0
* created_at timestamptz default now()

Cada usuário possui apenas uma wallet.

---

5. COMPRA DE MOEDAS

---

17. LIMPEZA AUTOMÁTICA DO CHAT

Mensagens devem ser removidas automaticamente após 24 horas.

Criar função SQL que delete:

messages WHERE created_at < now() - interval '24 hours'

---

18. SEGURANÇA

Ativar Row Level Security em todas as tabelas.

Criar policies para:

* usuários verem apenas seus dados sensíveis
* envio de mensagens apenas em lives ativas
* controle de inserção em wallets e earnings via funções SQL

---

19. FUNÇÕES IMPORTANTES

Criar funções SQL seguras para:

send_gift()

Fluxo:

debitar wallet do sender
registrar gift_transactions
creditar creator_earnings

---

claim_ad_reward()

Fluxo:

verificar se usuário já atingiu 25 minutos VIP no dia
se não → registrar ad_rewards
definir expires_at = now() + 5 minutos

---

claim_gift_reward()

Fluxo:

verificar valor total de presentes enviados no dia
se atingir meta → liberar VIP temporário
